# Font Awesome icons

- Source: https://github.com/FortAwesome/Font-Awesome/tree/6.7.2/svgs
- Version: Font Awesome Free 6.7.2.
- Icons: GitHub and Bilibili from Brands; Envelope from Regular; Book Open, Camera, Pause, Play, Arrow Up, and Arrow Up Right From Square from Solid.
- Original SVG files are retained unchanged. `sprite.svg` groups the same paths into named symbols for local reuse with `currentColor`.
